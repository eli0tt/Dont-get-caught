## 🎮 游戏简介

《课上偷吃大作战》是一款沉浸式的课堂摸鱼挑战游戏。你需要在老师的眼皮底下偷偷吃零食，警惕老师停笔回头，还要在关键时刻用课本掩护自己！

### 核心玩法
- 🍿 **空格偷吃**：快速敲击空格，在老师发现前吃掉它
- 👀 **老师警觉**：老师会随时停笔回头，你需要及时按下B键迅速打开课本
- 🧹 **抢救杂物**：桌面上会掉落杂物，要及时抢救避免引起噪音
